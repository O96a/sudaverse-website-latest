LLMCorpusKit

Repository
github.com/sudaverse/LLMCorpusKit (opens in a new tab)
License
MIT

Overview

LLMCorpusKit is a toolkit for cleaning and polishing large Arabic text corpora. Beyond rule-based cleaning, it uses AI-powered semantic repair to fix sentences and improve quality, so the corpus is suitable for training language models.

It works with language-model APIs to understand context, with the aim that the refined corpus stays linguistically coherent and culturally authentic.

Key features

Deep-cleaning workflows
Multi-stage cleaning pipelines that raise text quality step by step, from surface normalization to deep semantic analysis.
Sentence repair
AI-powered correction of sentence structure. It fixes grammatical errors, incomplete sentences and fragmented text while preserving meaning.
API integration
Integrates with language-model APIs for text enhancement and quality assessment.
Bulk and streaming
Efficient bulk processing for large corpora, and streaming for real-time data pipelines.

Installation and usage

Install the package with pip, then create a CorpusRefinery and point it at your raw corpus file.

Replace <provider> and <model> with values the toolkit supports, and never commit a real API key. The full API reference is in the repository README. LLMCorpusKit README (opens in a new tab)

Refinery stages

  1. Pre-processingBasic normalization and filtering.
  2. Semantic analysisContext understanding and validation.
  3. Repair and enhancementAI-powered text improvement.
  4. Quality assuranceAutomated quality checks.
  5. Post-processingFinal formatting and export.

Advanced features

Context-aware repair
Maintains discourse coherence across paragraphs.
Dialect preservation
Repairs text while preserving dialectal features.
Quality scoring
Assigns quality metrics to each text segment.
Parallel processing
Multi-threaded processing for large datasets.
Custom rules
An extensible rule engine for domain-specific refinement.

Pipeline overview

A general view of how raw text becomes a deployed model, and where LLMCorpusKit fits.

  1. CollectionGather raw Arabic text from your sources.
  2. Cleaning and normalizationInitial cleaning and normalization of the raw text.
  3. Refinement with LLMCorpusKitDeep cleaning and semantic repair.
  4. Model trainingTrain language models on the processed data.
  5. Benchmark evaluationAssess model performance.
  6. Application deploymentDeploy in production.

For tokenizers, the public benchmark below compares how efficiently they handle Sudanese dialect text. Sudanese Dialect Tokenizer Benchmark (opens in a new tab)

Contribution guidelines

Contributions to the public repositories are welcome: bug fixes, new features, documentation and ideas. Sudaverse is committed to a welcoming and inclusive environment for all contributors.

How to contribute

  1. Fork the repository you want to contribute to.
  2. Create a feature branch: git checkout -b feature-name
  3. Make your changes, following the coding standards of the project.
  4. Write tests for new features.
  5. Run the test suite to make sure nothing breaks.
  6. Submit a pull request with a clear description.

Contribution areas

Bug fixes, new features and optimizations.
Documentation

Add test cases and improve coverage.
Translation
Localize documentation.
